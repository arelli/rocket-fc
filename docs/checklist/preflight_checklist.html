1. At home, the day before arm link out, no charge fitted

  • Firmware on both kits from a clean commit: boot banner shows no -dirty. Note the commit above
  • UISettings → Read settings. Check for this motor: deploy_delay_ms, backup_deploy_ms, min_deploy_alt_m
  • UImanual_eject as intended (default 0 = off)
  • UINo rf_key default warning (both kits)
  • UISave to flash → Reboot rocket. Export… the settings file; note the CRC above
  • UIIf any flight-safety setting changed: BENCH mode → Flight computer → Simulated flight: LAUNCH, APOGEE, fire, LANDED in Events. Then Reboot rocket
  • UIIMU remounted? Rocket nose up, still → Attitude → Set upright → reboot. Tilt ≈ 0° upright
  • Wiring changed? Pyro test with bare nichrome first (docs/TESTING.md step 3)
  • UIFlight computer → List sessions: old flights downloaded; erase the flash log if nearly full
  • Flight cell (18350) charged: ≥ 4.1 V at rest
  • Ground station cell (18650), phone and power bank charged
  • Recovery packed: parachute, shock cord, wadding / protector, nose cone fits

2. Packing list

  • Rocket, flight computer, arm link (jumper / key)
  • Motors, motor igniters, ejection charges / e-matches
  • Spare charged 18350; USB-C data cable
  • Ground station with both antennas (LoRa on the Wio, 2.4 GHz WiFi on the XIAO)
  • Launch leads + clips, launch pad + rod/rail, blast deflector
  • Phone (station WiFi password saved), power bank
  • Multimeter, small screwdriver, tape, spare nichrome, cable ties
  • Fire extinguisher or water, first-aid kit
  • This sheet, pen; GPS module fitted (if used)
  • Laptop (optional): USB console, pio device monitor

3. Ground station setup at the field ARM switch OFF

  • BOXARM switch OFF, MODE switch = BENCH for now
  • BOXLoRa and WiFi antennas fitted; station placed near the pad with short launch leads
  • BOXPower on: ON LED steady (double blink = battery low)
  • Phone joins rocketfc-XXXX, opens http://192.168.4.1 (stay connected without internet)
  • UIPill "station: connected"
  • UIRadio link → Ground station → Battery: OK, not LOW
  • UIRadio link → Heartbeat to the rocket: on, pad beeps every 10 s → Apply
  • UILaunch panel shows "ARM off"

4. Flight computer prep in the prep area · arm link OUT · motor not in the pad

  • Arm link OUT. Ejection charge / e-match installed and wired to the igniter terminal
  • Main switch ON with the rocket still and vertical during the countdown ticks
  • 2 beeps = self-test OK. N long beeps = fault N (see page 2): do not fly
  • LED 1 flash/s (PAD, no continuity yet)
  • UIFlight: state PAD; IMU and BARO green; ARMED, FIRED, BATT LOW, RESUMED off
  • UIFlight: Battery ≥ 3.9 V; Altitude ≈ 0 m and steady
  • UIAttitude: tilt ≈ 0° with the rocket vertical
  • UIRadio link: "Rocket hears ground: yes", rate ≈ 1 /s, lost ≈ 0 %, SNR margin positive
  • UIPing rocket: rocket beeps, then the station beeps
  • UIGPS and recovery (if fitted): fix, satellites ≥ 6; pad position recorded
  • UIEjection charge: "MANUAL EJECT" pill only if you intend to use it
  • UIEvents: no unexpected warnings since boot
  • Parachute, wadding, nose cone closed; flight computer bay vented
  • Motor installed and retained; motor igniter not yet inserted

5. At the pad range clear · ARM switch OFF

  • Rocket on the rod / rail, moves freely; nose up
  • BOXMODE switch = FLIGHT
  • UINo BENCH banner; Flight state PAD
  • UILaunch: "rocket ready"
  • Fit the arm link LAST, from the side, never over the rocket
  • LED 2 quick flashes/s; 3 short beeps every 10 s (continuity)
  • UIFlight: CONTINUITY green; ARMED and FIRED still off
  • BOXARM OFF confirmed, then insert the motor igniter and clip the launch leads
  • UILaunch: still "ARM off", "igniter —"
  • BOXARM ON, the last action at the pad: 3 beeps, then a chirp every 2 s
  • UILaunch: ARMED, igniter OK, rocket ready
  • Walk straight back to the safety distance with the phone; nobody returns to the pad
  • Club rules require the arming key at the launch position? Use long leads and keep the station with you.

6. Launch from the safety distance

  • Range and sky clear; RSO / spotters ready; loud announcement
  • UILast look: rocket PAD, CONTINUITY, ARMED off, link fresh ("Last frame" < 2 s)
  • UILAUNCH (or the station button): countdown 3 s, then the igniter pulse
  • ABORT during the countdown stops it (or press the button again).
  • UIWatch Flight: BOOST → COAST → DESCENT; Events: LAUNCH, APOGEE, deployment
  • UINote Max altitude; GPS and recovery: "From the pad" distance and bearing
  • BOXAfter lift-off, when the pad is safe: ARM OFF

7. Misfire

  • UIABORT if still counting. Station beeps 3 short = refused / aborted
  • Wait at least 60 s before anyone approaches the pad
  • BOXARM OFF, unclip the launch leads, remove the motor igniter
  • Rocket arm link OUT before handling the rocket; then check the igniter and retry from section 5

8. Recovery and after the flight

  • UILost sight? GPS and recovery: last known position, distance and bearing from the pad
  • UIClose but hidden? Radio link → Search mode (or hold the station button 1.5 s): faster ticks = stronger signal
  • At the rocket: arm link OUT first (an unfired charge may still be live)
  • UIFlight: FIRED on? If not, treat the charge as live
  • Listen to the altitude beacon (1 long beep, then digits), note it, then main switch OFF
  • UIFlight computer → Rocket WiFi → List sessions → Download this flight
  • UISave radio log
  • Recharge both cells; replace the ejection charge and wadding
